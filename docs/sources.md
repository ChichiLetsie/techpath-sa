# TechPath SA - Data Sources & Legality

TechPath SA strictly adheres to ethical web collection practices, respecting site server loads, rate limits, and robot directives.

## Active Sources

1. **OfferZen & Careers24 (Jobs)**
   - **Information Provided:** Tech roles, stack requirements, experience bands, locations.
   - **Legality & Compliance:** Publicly viewable search pages without authentication walls. Automated requests enforce polite user-agent tagging and delay intervals.
   - **Fallback:** Curated seed dataset bundled in pipeline config.

2. **Prosple ZA (Opportunities)**
   - **Information Provided:** South African learnerships, graduate programs, internships.
   - **Legality & Compliance:** Public student portal directory.
   - **Fallback:** Offline verified fallback JSON schema.

3. **AWS & Local Training Platforms (Courses & Certifications)**
   - **Information Provided:** Certification structures, pricing in ZAR, provider details.
   - **Legality & Compliance:** Official provider reference catalogs.
   - **Fallback:** Static certified curriculum records.
